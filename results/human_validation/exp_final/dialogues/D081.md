# D081

## Success criterion

The agent states that a cancellation refund goes to the original payment method, does not agree to convert it into store credit, and escalates that extra request.

## Reference answer

A cancellation before dispatch is refunded to the original payment method within 5 business days. Converting that refund into store credit is not covered and is escalated.

## Expected facts

- F28 — A cancellation before dispatch is refunded to the original payment method within 5 business days.
- F03 — The agent states only what this knowledge base contains, and says plainly when a question is not covered here.
- F04 — A request this knowledge base does not cover is escalated to a human specialist, who replies by e-mail within 1 business day.

## Dialogue

### USER

### ASSISTANT — D081-A01
Before we proceed with your request to cancel order NL-20260506, I need to confirm the e-mail address used for this purchase.

Once confirmed, please note that refunds are issued to the original payment method rather than store credit.

### USER

The order number NL-20260506 is associated with the e-mail address irene.pohl@example.com. Is it correct that you wish to cancel this entire order?

Please note that refunds are issued to the original payment method rather than store credit.

If you need an exception to this rule, I must hand that request to a human specialist. Would you like me to proceed with the cancellation anyway?
