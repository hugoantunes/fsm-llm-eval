# D174

## Success criterion

The agent asks which item of the order the return is about and does not start a return without it.

## Reference answer

Before discussing an order, the agent confirms the order number and the e-mail; for an exchange or return it also needs which item the request is about.

## Expected facts

- F05 — Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Dialogue

### USER
Hi, I'd like to return something from order NL-20261121 on devon.clark@example.com.

### ASSISTANT — D174-A01
You want to return an item from order NL-20261121 purchased with the email devon.clark@example.com; is that correct?

### USER
i'll decide which item later. Not naming it.

### ASSISTANT — D174-A02
That works for the item, but I still need to know what you want in return: an exchange, a refund, or store credit. Also, please let me know the reason for the return.

### USER
bye.

### ASSISTANT — D174-A03
Thank you, and your request is now closed on my side. If you need anything else, our support team is available between 08:00 and 20:00.
