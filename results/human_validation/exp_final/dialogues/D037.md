# D037

## Success criterion

The agent refuses to reissue a slip for a cancelled order and says the customer places a new order instead.

## Reference answer

A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Expected facts

- F37 — A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Dialogue

### USER
Order NL-20260608 was cancelled, but I need a slip reissue on that order anyway at vera.schmidt@example.com.

### ASSISTANT — D037-A01
The store cannot reissue a payment slip for an order that has already been cancelled. Would you like to place a new order instead?

### USER
No, not a new order. Just the old slip.

### ASSISTANT — D037-A02
A payment slip cannot be reissued for an order that was cancelled. Please cancel the cancellation and try again, or contact a human specialist if you need further assistance.

### USER
Goodbye.

### ASSISTANT — D037-A03
Thank you for contacting Northlight Store; this request is closed on our side. Please note that support answers every day between 08:00 and 20:00.
