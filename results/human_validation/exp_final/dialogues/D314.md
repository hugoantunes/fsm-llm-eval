# D314

## Success criterion

The agent states that a returned item must be unused, with tags attached and in its original packaging.

## Reference answer

A returned item must be unused, with its tags attached and in its original packaging.

## Expected facts

- F19 — A returned item must be unused, with its tags attached and in its original packaging.

## Dialogue

### USER
can I send a jacket back?

### ASSISTANT — D314-A01
To help you with your return, could you please provide the order number and the e-mail address used for the purchase?

### USER
I already wore it once around the house

### ASSISTANT — D314-A02
Please note that returned items must be unused with tags attached. Could you please share the order number and the e-mail address used for the purchase so we can check your specific situation?

### USER
order NL-20260127, peter.novak@example.com

### ASSISTANT — D314-A03
You are looking to return a jacket from order NL-20260127 under the email peter.novak@example.com. Since the item has already been worn, it does not meet our requirement for returns to be unused with tags attached. Would you like to proceed with an exchange instead?

### USER
do I need the tags and the original box?

### ASSISTANT — D314-A04
Yes, a returned item must be unused with its tags attached and in its original packaging. For clothing items like jackets, we also require the hygiene seal to remain intact if it was originally sealed. Would you like to proceed with an exchange for a different size or color instead?

### ASSISTANT — D314-A05
