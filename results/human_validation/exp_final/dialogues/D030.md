# D030

## Success criterion

The agent asks which item of the order the return is about and does not start a return without it.

## Reference answer

Before discussing an order, the agent confirms the order number and the e-mail; for an exchange or return it also needs which item the request is about.

## Expected facts

- F05 — Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Dialogue

### USER
Hi, I'd like to return something from order NL-20261121 on devon.clark@example.com.

### ASSISTANT — D030-A01
Thank you for contacting Northlight Store support. Could you please tell me which item from your order you wish to return and the reason for the return?

### USER
I'll decide which item later. Not naming it.

### ASSISTANT — D030-A02
I understand, but I need to know the specific item and the reason for the return before I can proceed with any details. Could you please provide those now?

### USER
Bye.

### ASSISTANT — D030-A03
Thank you for contacting Northlight Store support. As this request is incomplete without the specific item and reason, I will need to hand this over to a human specialist once you are ready to continue. Our support hours are between 08:00 and 20:00, so please feel free to return during that time if you wish to speak directly with an agent.
