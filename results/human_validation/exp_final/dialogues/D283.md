# D283

## Success criterion

The agent asks for the e-mail and does not reissue a slip without confirming identity.

## Reference answer

Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Expected facts

- F05 — Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

### USER

### USER
no mail

### USER
reissue anyway

I cannot proceed with reissuing a slip until I have confirmed both the order number and the e-mail address used for the purchase. Could you please provide the e-mail address?
