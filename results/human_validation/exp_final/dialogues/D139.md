# D139

## Success criterion

The agent treats tracking as the request, confirms identity, says where the tracking code is, and does not start a cancellation.

## Reference answer

The tracking code is sent by e-mail at dispatch and also appears in the order history of the customer's account.

## Expected facts

- F12 — The tracking code is sent by e-mail at dispatch and also appears in the order history of the customer's account.
