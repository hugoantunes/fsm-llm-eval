# D331

## Success criterion

The agent states the 7-day promotional window, does not apply the 30-day rule to the promotional item, and does not start an exchange.

## Reference answer

An item bought on promotion can be exchanged or returned within 7 calendar days of delivery, not the usual 30, so a jacket delivered 20 days ago is outside the window.

## Expected facts

- F18 — An item bought on promotion can be exchanged or returned within 7 calendar days of delivery, not the usual 30.

## Dialogue

### USER
Hi, I need to exchange my sale jacket from order NL-20260409 which was delivered 20 days ago. The email on file is walt.reed@example.com.

### ASSISTANT — D331-A01
Thanks for the details; before we proceed with your request to exchange the blue jacket, please confirm that you would like an exchange and specify the reason for it.

### USER
I want to exchange it because I changed my mind. The window is 30 days for everything.

### ASSISTANT — D331-A02
Thank you; since your order was delivered 20 days ago and our policy allows returns within 30 calendar days, this request is valid. Please confirm whether you would prefer a refund or store credit if the jacket is out of stock in the size you want.

### USER
What can be done about the jacket?

### ASSISTANT — D331-A03
The jacket can be exchanged for a different size if available, or returned for a refund or store credit if your preferred size is unavailable. Please confirm which option you prefer.

### USER
goodbye

### ASSISTANT — D331-A04
You are welcome; thank you for contacting us today. If you would like to proceed with the exchange or return for your blue jacket, please reply with your choice of refund or store credit so we can continue. Our support team answers every day between 08:00 and 20:00.
