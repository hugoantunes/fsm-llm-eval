# D250

## Success criterion

The agent says that changing the payment method of an existing order is not covered and escalates.

## Reference answer

Changing the payment method of an existing order is not covered. The request is escalated to a human specialist.

## Expected facts

- F03 — The agent states only what this knowledge base contains, and says plainly when a question is not covered here.
- F04 — A request this knowledge base does not cover is escalated to a human specialist, who replies by e-mail within 1 business day.

## Dialogue

### USER
I want to switch NL-20260514 from slip to card for owen.blake@example.com, please don't reissue.

### ASSISTANT — D250-A01
I can assist with exchanging, returning, or cancelling your order, but I cannot change the payment method from a slip to a card. This request is outside of what our automated system handles and will need to be reviewed by a human specialist. Could you please confirm which action you would like to take for order NL-20260514?

### USER
Can we do it with card on the same order?

### ASSISTANT — D250-A02
I am unable to switch the payment method from slip to card for an existing order. Our system does not support changing how an order was paid once it has been placed. To proceed, you would need to cancel this order and place a new one with a card; please note that items will only be held in stock for 3 business days. Would you like me to help you start the cancellation process?

### USER
bye

### ASSISTANT — D250-A03
Thank you for your time, Owen. If you decide later to cancel order NL-20260514 and place a new one, please remember our support hours are between 08:00 and 20:00. I hope you have a great day.
