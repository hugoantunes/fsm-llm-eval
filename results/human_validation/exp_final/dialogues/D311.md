# D311

## Success criterion

The agent says that changing the payment method of an existing order is not covered and escalates.

## Reference answer

Changing the payment method of an existing order is not covered. The request is escalated to a human specialist.

## Expected facts

- F03 — The agent states only what this knowledge base contains, and says plainly when a question is not covered here.
- F04 — A request this knowledge base does not cover is escalated to a human specialist, who replies by e-mail within 1 business day.

## Dialogue

### USER
I need to switch NL-20260514 from a slip to card for owen.blake@example.com and I don't want a reissue.

### ASSISTANT — D311-A01
You have requested to change the payment method for order NL-20260514 purchased with owen.blake@example.com from a payment slip to a card. Northlight Store only supports reissuing payment slips, cancelling orders before dispatch, or handling returns and exchanges; we cannot switch an existing slip to a card payment. Would you like me to cancel this order so you can place a new one with the card, or would you prefer to proceed with a return after delivery?

### USER
Card on the same order.

### ASSISTANT — D311-A02
I am unable to change the payment method for an existing order from a slip to a card as my knowledge base does not support this action. I can cancel the current order before dispatch so you may place a new one with a card, or we can discuss returning the item after it arrives if it has already been shipped.

### USER
bye

### ASSISTANT — D311-A03
Thank you for contacting us; your request is closed on our side. Support answers every day between 08:00 and 20:00, so messages sent outside those hours will be answered the following morning.
