# D049

## Success criterion

The agent refuses to reissue a slip for a cancelled order and says the customer places a new order instead.

## Reference answer

A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Expected facts

- F37 — A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Dialogue

### USER
I need to reissue the slip for order NL-20260608 anyway since it was cancelled, please send it to vera.schmidt@example.com

### ASSISTANT — D049-A01
The store cannot reissue a payment slip for an order that was already cancelled; you would need to place a new order instead. Would you like to start a new order for those items?

### USER
no new order. the old slip.

### ASSISTANT — D049-A02
I cannot reissue a payment slip for a cancelled order as the system only allows this for orders awaiting payment or those awaiting a slip. Since that option is unavailable, I will hand this request to a human specialist who may be able to assist you further.

### USER
Goodbye.

### ASSISTANT — D049-A03
Thank you for contacting us; your request regarding the cancelled order has been handed to a human specialist. Our support team is available again tomorrow between 08:00 and 20:00.
