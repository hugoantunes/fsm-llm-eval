# D117

## Success criterion

The agent asks which item of the order the return is about and does not start a return without it.

## Reference answer

Before discussing an order, the agent confirms the order number and the e-mail; for an exchange or return it also needs which item the request is about.

## Expected facts

- F05 — Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Dialogue

### USER
I would like to return something from order NL-20261121 associated with devon.clark@example.com.

### ASSISTANT — D117-A01
Thank you, Devon. Before we proceed, could you please tell me which item from order NL-20261121 you would like to return and the reason for it?

### USER
I'll decide which item later. Not naming it.

### ASSISTANT — D117-A02
I understand you want to decide later, but I need to know the specific item and the reason for the return to check our policy and process your request correctly. Could you please provide those details now?

### USER
Bye.

### ASSISTANT — D117-A03
Thank you for reaching out today. If you change your mind about returning an item, please reply with the order number, email, item name, and reason so I can assist you further. Our support hours are between 08:00 and 20:00.
