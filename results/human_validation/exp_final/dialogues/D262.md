# D262

## Success criterion

The agent says that a points programme is not covered and escalates; it invents no points rule.

## Reference answer

A points programme is not covered. The request is escalated to a human specialist.

## Expected facts

- F03 — The agent states only what this knowledge base contains, and says plainly when a question is not covered here.
- F04 — A request this knowledge base does not cover is escalated to a human specialist, who replies by e-mail within 1 business day.

## Dialogue

### USER
Hi, I'd like to cancel order NL-20260321 for ben.carter@example.com. If I do that, will I lose any loyalty points?

### ASSISTANT — D262-A01
Before we proceed, please confirm that ben.carter@example.com is the e-mail address used for purchase of order NL-20260321. Regarding your question about loyalty points: our knowledge base does not contain information on how cancellations affect them, so I cannot answer that part and will need to hand it to a human specialist once we sort out the order status.

### USER
How many points lost?

### ASSISTANT — D262-A02
Our records do not show how many points would be lost upon cancellation, as this information is not covered in our current guidelines. I can only confirm that cancelling an order cancels all its items; a human specialist will need to address your question about the specific point deduction.

### USER
bye

### ASSISTANT — D262-A03
Thank you for contacting us. Since our knowledge base does not cover loyalty point deductions, a human specialist will need to handle that part of your request. You may return between 08:00 and 20:00 if you have further questions about the order cancellation itself.
