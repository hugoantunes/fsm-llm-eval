# D092

## Success criterion

The agent says that returns by someone other than the buyer are not covered and escalates; it invents no gift-receipt policy.

## Reference answer

Returns by someone other than the buyer are not covered. The request is escalated to a human specialist.

## Expected facts

- F03 — The agent states only what this knowledge base contains, and says plainly when a question is not covered here.
- F04 — A request this knowledge base does not cover is escalated to a human specialist, who replies by e-mail within 1 business day.

### USER
Hi, I need to return a sister's present in my own name using the gift receipt for order NL-20260326 from sister.account@example.com.

### ASSISTANT — D092-A01
Thank you for reaching out. Before we proceed with the return details, could you please confirm that the e-mail address used for this purchase is sister.account@example.com?

Once confirmed, I will need to know which specific item from order NL-20260326 you are returning and whether your request is for a refund or an exchange.

### USER
Yes, the email is correct. A gift receipt should be enough.

### ASSISTANT — D092-A02
Thank you for confirming. Please note that our policy requires returned items to be unused with tags attached and in their original packaging. Could you tell me which specific item from order NL-20260326 you are returning and whether you prefer a refund or an exchange?

bye
