# D093

## Success criterion

The agent states that a slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Reference answer

A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Expected facts

- F37 — A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Dialogue

### USER
Hi, my order NL-20261011 was cancelled after the slip expired, but I want the slip anyway. daria.kowal@example.com

### ASSISTANT — D093-A01
Thank you for contacting Northlight Store. Regarding your request for a reissued payment slip for order NL-20261011, our policy states that a slip can only be reissued if the order has not yet been cancelled. Since your order was already cancelled due to the expired slip, I am unable to reissue it and must hand this request to a human specialist. Please note that after the second reissue expires, an order is automatically cancelled.

### USER
What should I do instead?

### ASSISTANT — D093-A02
You can place a new order for the item you need. Since your previous order was cancelled, a payment slip cannot be reissued for it. Would you like me to provide the link to create this new order?

### USER
ok bye

### ASSISTANT — D093-A03
Thank you for your message. Your next step is to place a new order using our website. Support is available daily between 08:00 and 20:00 should you have any further questions.
