# D302

## Success criterion

The agent says that a manufacturing warranty after the return window is not covered and escalates; it invents no warranty period.

## Reference answer

The warranty for defects found after the return window is not covered. The request is escalated to a human specialist.

## Expected facts

- F03 — The agent states only what this knowledge base contains, and says plainly when a question is not covered here.
- F04 — A request this knowledge base does not cover is escalated to a human specialist, who replies by e-mail within 1 business day.
