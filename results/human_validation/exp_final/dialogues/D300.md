# D300

## Success criterion

The agent asks which item of the order the return is about and does not start a return without it.

## Reference answer

Before discussing an order, the agent confirms the order number and the e-mail; for an exchange or return it also needs which item the request is about.

## Expected facts

- F05 — Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Dialogue

### USER
I would like to return something from order NL-20261121 associated with devon.clark@example.com.

### ASSISTANT — D300-A01
You want to return an item from order NL-20261121 purchased with devon.clark@example.com, is that correct?

### USER
i'll decide which item later, not naming it.

### ASSISTANT — D300-A02
That works; I just need the reason for the return and whether you want an exchange, refund, or store credit before we proceed.

### USER
bye

### ASSISTANT — D300-A03
Thank you for contacting Northlight Store; your request has been closed on my side. Please note that support answers every day between 08:00 and 20:00 if you need to reach a human specialist for further assistance.
