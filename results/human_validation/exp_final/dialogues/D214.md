# D214

## Success criterion

The agent draws out which item and the order details, then states the 30-day return window.

## Reference answer

Any item can be returned within 30 calendar days of delivery, with no reason required.

## Expected facts

- F17 — Any item can be returned within 30 calendar days of delivery, with no reason required.

## Dialogue

### USER
I need to send something back.

### ASSISTANT — D214-A01
To process your return, I first need to confirm your order number and the e-mail address used for the purchase.

### USER
It's NL-20260909, grey trainers delivered 12 days ago, kai.anders@example.com

### ASSISTANT — D214-A02
You mentioned a return for order NL-20260909 purchased with email kai.anders@example.com. Was this the correct request you wanted to proceed with?

### USER
reason required?

### ASSISTANT — D214-A03
A reason is not required for a standard return, but I still need to know which specific item (for example: the grey trainers) and whether you want an exchange, a refund or store credit.

### USER
bye

### ASSISTANT — D214-A04
Thank you for contacting Northlight Store; your request is closed on our side. If you change your mind about the return, please reach out again between 08:00 and 20:00.
