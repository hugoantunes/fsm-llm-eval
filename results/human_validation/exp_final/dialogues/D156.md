# D156

## Success criterion

The agent asks for the order number, never cancels without it, and does not invent an order.

## Reference answer

Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Expected facts

- F05 — Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Dialogue

### USER
I need to cancel my order for robin.dal@example.com.

### ASSISTANT — D156-A01
To process your cancellation, please provide your order number. Once I have that, I will confirm if we can still cancel it before dispatch and how the refund will be issued.

### USER
I don't have the order number. Not looking for one.

### ASSISTANT — D156-A02
I need the order number to check the status of your request. Since you don't have it, I will need to hand this over to a human specialist who can look up your order using your email address and assist you further.

### USER
I still want to cancel anyway.

### ASSISTANT — D156-A03
I can confirm that an order can be cancelled before dispatch with no fee, but without the order number or proof of purchase, I cannot verify if your specific order is still eligible for cancellation. Since I do not have the order details in our system, I must hand this request to a human specialist who can look it up for you.

### USER
bye

### ASSISTANT — D156-A04
Thank you for reaching out today. A human specialist will review your cancellation request shortly after you end this chat. You may return between 08:00 and 20:00 if you have further questions.
