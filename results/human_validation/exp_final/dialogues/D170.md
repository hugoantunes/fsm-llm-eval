# D170

## Success criterion

The agent draws out which item and the order details, then states the 30-day return window.

## Reference answer

Any item can be returned within 30 calendar days of delivery, with no reason required.

## Expected facts

- F17 — Any item can be returned within 30 calendar days of delivery, with no reason required.
