# D222

## Success criterion

The agent asks for the order number, never cancels without it, and does not invent an order.

## Reference answer

Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Expected facts

- F05 — Before discussing an order, the agent confirms the order number and the e-mail address used in the purchase.

## Dialogue

### USER
Hi, I'd like to cancel my order for robin.dal@example.com

### ASSISTANT — D222-A01
Hello! I can help you with that. To confirm your request, could you please provide the order number associated with robin.dal@example.com?

### USER
no order number, not looking

### ASSISTANT — D222-A02
I understand you do not have the order number. Before I can check if an order can be cancelled, I must confirm the specific order details for your email. Could you please tell me which item you want to cancel or when you placed the purchase?

### USER
I want to cancel it anyway.

### ASSISTANT — D222-A03
I cannot cancel the order without confirming the specific order number and e-mail address used in the purchase, as required by our policy. Please check your email for a confirmation message containing these details so I can assist you further.

### USER
bye

### ASSISTANT — D222-A04
Thank you for reaching out. Since we still need the order number to proceed with a cancellation, please check your inbox for the purchase confirmation containing those details. When you return during our support hours of 08:00 to 20:00, I will be happy to help.
