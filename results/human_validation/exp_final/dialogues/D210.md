# D210

## Success criterion

The agent refuses to cancel after dispatch and points to refusing delivery or opening a return; it does not override dispatch.

## Reference answer

After dispatch an order can no longer be cancelled: the customer refuses the delivery or opens a return.

## Expected facts

- F27 — After dispatch an order can no longer be cancelled: the customer refuses the delivery or opens a return.

## Dialogue

### USER
I need to cancel order NL-20260412 even though it dispatched for zoe.martin@example.com.

### ASSISTANT — D210-A01
I cannot cancel order NL-20260412 because it has already been dispatched. Once an order is on its way, it must be refused upon delivery or returned instead. Would you like to know the details of our return process for this item?

### USER
I will not refuse delivery and I will not open a return. Cancel it.

### ASSISTANT — D210-A02
I cannot cancel order NL-20260412 because it has already been dispatched; according to policy, an order awaiting payment is cancelled automatically only if a slip expires, but once shipped, cancellation is no longer possible. Since you have declined the refusal or return options, this request must be handled by a human specialist who will email you within one business day.

### USER
Goodbye.

### ASSISTANT — D210-A03
Thank you for contacting Northlight Store support. As order NL-20260412 has already been dispatched, it cannot be cancelled and requires assistance from a human specialist. You may return to chat between 08:00 and 20:00 if you need further help.
