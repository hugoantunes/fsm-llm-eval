# D057

## Success criterion

The agent states that after dispatch the order can no longer be cancelled; the customer refuses the delivery or opens a return.

## Reference answer

After dispatch an order can no longer be cancelled: the customer refuses the delivery or opens a return.

## Expected facts

- F27 — After dispatch an order can no longer be cancelled: the customer refuses the delivery or opens a return.

## Dialogue

### USER
I wanted NL-20260728 cancelled but I just found out it has already been dispatched. This is for tomas.berk@example.com.

### ASSISTANT — D057-A01
I cannot cancel order NL-20260728 because it has already been dispatched. Once an order leaves our warehouse, the cancellation process stops and you must refuse the delivery or open a return instead. Would you like to start a return for this order?

### USER
instead of cancelling what can I do?

### ASSISTANT — D057-A02
You can refuse the delivery when it arrives to get a full refund, or you can open a standard return within 30 days of delivery if the item is unused. Which option would you prefer?

### USER
thanks, goodbye

### ASSISTANT — D057-A03
Thank you for contacting Northlight Store. You may refuse the delivery or start a return to get your money back. Our support team is available daily from 08:00 to 20:00 if you need further help with that.
