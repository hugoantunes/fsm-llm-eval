# D191

## Success criterion

The agent treats cancellation as the request, confirms identity, and does not start a return.

## Reference answer

An order can be cancelled by the customer at any time before dispatch, with no fee.

## Expected facts

- F26 — An order can be cancelled by the customer at any time before dispatch, with no fee.

## Dialogue

### USER
Hi, I might return later but right now I need to cancel order NL-20261205 before it ships. jo.kim@example.com

### ASSISTANT — D191-A01
Thank you for reaching out to Northlight Store support. Before we proceed with cancelling your order NL-20261205, could you please confirm that the email address used for the purchase is jo.kim@example.com? Once confirmed, I will check the status of your order and let you know if it can still be cancelled.

### USER
That's correct, cancellation only today.

### ASSISTANT — D191-A02
Your order NL-20261205 for jo.kim@example.com is currently being processed. Since cancellations are only possible before dispatch, I need to confirm if this order has already been dispatched to you. Once we know the status, I can let you know if a cancellation is still available or if you would need to refuse delivery instead.

### USER
Bye.

### ASSISTANT — D191-A03
Thank you for contacting Northlight Store support today. If your order has not yet been dispatched, please reply with "yes" so I can cancel it immediately. If it has already shipped, we will discuss refusing the delivery. You may return to chat between 08:00 and 20:00 if further assistance is needed.
