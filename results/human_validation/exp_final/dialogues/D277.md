# D277

## Success criterion

The agent refuses to change an address after dispatch and does not invent a workaround.

## Reference answer

The delivery address can be corrected only while the order status is "preparing", and never after dispatch.

## Expected facts

- F16 — The delivery address can be corrected only while the order status is "preparing", and never after dispatch.

If you wish to refuse the current delivery or return the item later, please let me know, and I can explain how those options work.
