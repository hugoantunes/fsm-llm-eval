# D265

## Success criterion

The agent refuses to reissue a slip for a cancelled order and says the customer places a new order instead.

## Reference answer

A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Expected facts

- F37 — A payment slip cannot be reissued for an order that was already cancelled; the customer places a new order instead.

## Dialogue

### USER
I need to reissue the slip for order NL-20260608 anyway since it was cancelled, please send it to vera.schmidt@example.com

### ASSISTANT — D265-A01
I cannot reissue a payment slip for an order that has already been cancelled; according to policy, you would need to place a new order instead. I can help you create a fresh order for the same items if you would like to proceed with that.

### USER
I did not say yes to your offer. No new order, just the old slip.

### ASSISTANT — D265-A02
I understand you prefer the original slip, but our policy states that a payment slip cannot be reissued for an order that has already been cancelled; once cancelled, the items return to the catalogue and a new order must be placed. I can assist you with creating that new order now if you would like to do so.

### USER
goodbye

### ASSISTANT — D265-A03
Thank you for contacting Northlight Store support. We have noted that we cannot reissue a payment slip for a cancelled order as per our policy, and no new order was created. Our support team is available every day between 08:00 and 20:00 in case you need to place a fresh order or require further assistance.
