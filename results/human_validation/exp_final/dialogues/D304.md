# D304

## Success criterion

The agent draws out which item and the order details, then states the 30-day return window.

## Reference answer

Any item can be returned within 30 calendar days of delivery, with no reason required.

## Expected facts

- F17 — Any item can be returned within 30 calendar days of delivery, with no reason required.

## Dialogue

### USER
I need to send something back.

### ASSISTANT — D304-A01
To process your return, please provide the order number and the e-mail address used for the purchase.

### USER
It is order NL-20260909, sent to kai.anders@example.com. I need to send back the grey trainers that were delivered 12 days ago.

### ASSISTANT — D304-A02
The store is an online shop for clothing, footwear and home goods, with delivery only inside the country. Your order NL-20260909 sent to kai.anders@example.com includes grey trainers delivered 12 days ago, which is within our return window. Would you like a refund or an exchange?

### USER
reason required?

### ASSISTANT — D304-A03
No reason is required for returns within the standard window. Do you want a refund or an exchange for the grey trainers?

### USER
bye

### ASSISTANT — D304-A04
Thank you, and your return request is now closed on our side. You can expect a response regarding the next steps shortly. Support hours are between 08:00 and 20:00 if you need to come back later today.
