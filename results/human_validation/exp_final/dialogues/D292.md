# D292

## Success criterion

The agent states the 7-day promotional window, does not apply the 30-day rule to the promotional item, and does not start an exchange.

## Reference answer

An item bought on promotion can be exchanged or returned within 7 calendar days of delivery, not the usual 30, so a jacket delivered 20 days ago is outside the window.

## Expected facts

- F18 — An item bought on promotion can be exchanged or returned within 7 calendar days of delivery, not the usual 30.

## Dialogue

### USER
Hi, I need to exchange my sale jacket from order NL-20260409 which was delivered 20 days ago. The email on file is walt.reed@example.com.

### ASSISTANT — D292-A01
You are looking to exchange the jacket from order NL-20260409, purchased with the email walt.reed@example.com. Since this item was received 20 days ago, it is within our standard 30-day return window. Does that match your request?

### USER
Yes, the window is 30 days for everything.

### ASSISTANT — D292-A02
Great, please tell me the reason for the exchange, such as whether the size is too small or if you need a different item.

### USER
The jacket I got in that sale is just not right for me.

### ASSISTANT — D292-A03
You mentioned the jacket from order NL-20260409 received 20 days ago isn't quite right. Since this was a promotional item, your return window is actually 7 calendar days, so I cannot process an exchange at this point. Please let me know if you would like to cancel the pending request or if there is anything else I can assist you with.

### USER
The window is 30 days for everything. What can be done about the jacket?

### ASSISTANT — D292-A04
Northlight Store sells clothing, footwear and home goods online, with delivery only inside the country. The store's policy states that promotional items have a specific 7-day return window instead of the standard 30 days, so this request is not covered here. I will hand this to a human specialist who will reply by e-mail within 1 business day. Would you like me to offer assistance with an order request instead?

### USER
goodbye

### ASSISTANT — D292-A05
Thank you for contacting Northlight Store; your request has been closed on our side and escalated to a specialist who will email you by tomorrow morning. Our support team answers every day between 08:00 and 20:00.
